# Winterfold credits

Winterfold is an original game made for Study Desk. The code, the paper-map drawing, the pines, the interface, and the little synthesized sounds were written for this project.

No artwork, audio, type, or text was taken from Ski Lines: Trail Map or from any other ski game. The hills (Lark Basin, Copper Comb, Glass Saddle, and White Hour) are fictional. Real resort names are not used.

No CC0 or other third-party asset packs are included. Browser audio is generated with the Web Audio API at runtime.
