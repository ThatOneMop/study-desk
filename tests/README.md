Run from the website root: `python tests/assets.py` and `python tests/selected-indie.py`. DOM tests require Node and jsdom 26: install jsdom in a separate test workspace, then run `tests/dom-checks.cjs`, `tests/catalog-launch.cjs`, `tests/curation-regression.cjs`, `tests/arcade.cjs` and `tests/arcade-disabled.cjs` (GameMonetize and GameDistribution stay hidden, with no GameMonetize embed, until their own switches are on) and `python tests/arcade-build-parity.py` (catalogue generator matches the committed files) and `tests/shell-picks-and-saves.cjs` with `NODE_PATH` pointing to that workspace node_modules. `tests/relaxed-browser.cjs`, `tests/shell-browser.cjs`, `tests/game-smoke-browser.cjs` (title-to-play smoke test; `BASE` overrides the server) need Playwright and `python -m http.server 8765` in this folder. Set `CHROME_PATH` when using the system Chrome instead of Playwright's downloaded browser. No test dependencies are needed to host the website.

Run `node tests/gameplay-upgrades.cjs` with the same jsdom NODE_PATH for progression, save migration, rewards, bike-course completion and gameplay UI regression coverage.

Run all offline engine/DOM scripts with `NODE_PATH=<test workspace>/node_modules python3 tools/test-engines.py`. This excludes Playwright scripts and the gate fixture. GitHub pull requests and main run this suite automatically before Pages publication.
