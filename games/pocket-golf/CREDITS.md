# Pocket Golf

Original browser game created for Study Desk, 2026. Original code and procedural canvas art; no third-party game source or assets are bundled. Study Desk's shared bridge retains its MIT notice in ../../bridge.js.

Drag backwards from the ball and release to putt, tap the course to aim, or use the aim/power sliders and Putt button. Arrow keys adjust aim and power; Space puts. Nine seeded procedural holes use a guaranteed opening between wall sections, sand, banks and a slow-speed cup. Personal bests are local to this browser. Course generation is procedural rather than nine hand-authored levels.
