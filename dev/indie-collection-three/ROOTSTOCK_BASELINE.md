## Game

Original trait-recombination nursery puzzle in `games/rootstock`. Pick two different parent trees and one of five crossover points. Preview two complementary offspring, perform the cross, then keep one new cultivar. A seedling can become a parent. Six pots impose a nursery capacity; pruning frees a pot and retains its discovery in the album. Match six traits to deliver a request, then start the next request with preserved discoveries and crossing records. This is stylized deterministic inheritance, not a botanical simulation.

The three baseline requests require two, two and one crosses along the tested routes. There is no timer or arbitrary level count. No loss phase is claimed: poor pruning can remove useful parent traits, and a confirmed restart restores initial stock without deleting discoveries or records. The unique save key is `study-desk-rootstock-v1`. Original CSS tree shapes and system glyphs use no third-party asset collection.
