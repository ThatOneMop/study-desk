The workshop uses planned profile shaping: choose a station, plane width and direction, shave one layer across the covered stations, repair against-grain tear-out, and deliver the requested profile. Delivery coins purchase wider planes and fine abrasive; generated later boards mix grain directions. Replacing spoiled stock retains earned tools and coins.

This differs from the existing The Quiet Cut, whose fetched source describes timed blade taps inside a moving guide. Grainwright uses spatial stroke planning and surface repair, not that timing loop or its source/assets. Original SVG wood artwork and engine/UI code were written for this candidate. The development tree contained no AGENTS.md. Existing vanilla engine/UI/bridge and CI conventions were followed.
