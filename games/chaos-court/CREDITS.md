# Chaos Court

Original browser game created for Study Desk, 2026. Original code and procedural canvas art; no third-party game source, sprites, music or trademarked characters are bundled. The three sports use common sporting rules and original arcade mechanics. Study Desk's shared bridge retains its MIT notice in ../../bridge.js.

Keyboard: Blue A/D move, W jump and strike. Coral left/right arrows move, up arrow jumps and strikes. On-screen buttons support touch. Local play shares one device. Solo mode uses a computer opponent. First to five wins; each point changes the physics modifier. This is a compact 2D arcade game, not a port of Basket Random, Volley Random or Soccer Random.
