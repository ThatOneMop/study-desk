Run from the website root: `python tests/assets.py` and `python tests/selected-indie.py`. DOM tests require Node and jsdom 26: install jsdom in a separate test workspace, then run `tests/dom-checks.cjs`, `tests/catalog-launch.cjs` and `tests/curation-regression.cjs` with `NODE_PATH` pointing to that workspace node_modules. No test dependencies are needed to host the website.
