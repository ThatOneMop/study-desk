LET THE QUIET RING
How the mountain listens

Match the eight-beat engraving using the stones. Shift moves a stone's rhythm left or right around the loop. Later rooms unlock tuning between three voices and letting unwanted stones sleep.

The chorus must match every beat exactly before Perform opens. Then tap the named voice. Chords need both voices in any order; silence needs Rest. There is no timer and sound is optional. Five clashes fracture the seam.

One medal for release, one for no clashes, one for arranging within the room's move target. Replays keep only the best result. Six original rooms; this is a short prototype, with no hours-of-content claim.

All controls support Tab and Enter. During performance use 1 / 2 / 3 and Space for rest. Progress saves after each action when browser storage is available. Retry resets this room, not your records.

Undo reverses one shift, tune, strike or reward. Retry, room changes and reload clear undo. Space activates focused buttons normally; away from buttons it plays Rest. The attempt ledger shows live medal eligibility; it never changes the score.
