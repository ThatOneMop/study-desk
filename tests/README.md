Run from the website root: `python tests/assets.py` and `python tests/selected-indie.py`. DOM tests require Node and jsdom 26: install jsdom in a separate test workspace, then run `tests/dom-checks.cjs`, `tests/catalog-launch.cjs`, `tests/curation-regression.cjs` and `tests/shell-picks-and-saves.cjs` with `NODE_PATH` pointing to that workspace node_modules. `tests/relaxed-browser.cjs`, `tests/shell-browser.cjs`, and the Chromium half of `tests/direct-collection-boot.cjs` need Playwright and `python -m http.server 8765` in this folder. That Chromium half opens every bundled catalogue game and fails on a page error. Set `CHROME_PATH` when using the system Chrome instead of Playwright's downloaded browser. No test dependencies are needed to host the website.
