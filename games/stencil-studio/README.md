# Stencil Studio

Original third-collection game 41, selected for its calm spatial printmaking and selective ink repair. Three compact authored commissions; no content-hours claim. Code, CSS art and SVG cover are original, without external assets or runtime dependencies.

Position and rotate three shapes; mix Sea, Rose and Sun inks, or lift one channel while preserving later layers. Every print/lift uses one of five operations; undo and fresh sheets permit experimentation. Optional planned comparisons explain missing/excess ink before spending. A full-size selected-square guide supports narrow screens.

Arrow keys move, R rotates, Z undoes and Space prints outside native controls; all actions also have touch controls. Progress, setup and best-operation records use the existing study-desk-stencil-studio-v1 key. Malformed saves are retained until explicit recovery. Clear studio resets only this game. Games returns to the top-level catalogue from both standalone and embedded play.
