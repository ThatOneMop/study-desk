# Lanewright credits

Lanewright is an original game made for Study Desk. The simulation, the map drawing, the interface, and the sounds were written for this project.

No artwork, audio, type, or text was taken from Mini Motorways or from any other road game. The cities (Larkmere, Pebble Quay, Kiln Ridge, Saltglass, Reed Crossing, Moth Terrace, Cinder Steps, and Halo Basin) are fictional.

Browser audio is generated with the Web Audio API at runtime. No sampled music or effects are included. Saves use `study-desk-lanewright-v1` only.

Mechanics notes, including which public pages were read, are in `docs/lanewright-research.md`.
